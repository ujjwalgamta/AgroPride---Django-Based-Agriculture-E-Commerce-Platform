## 📖 Project Overview

**AgroPride** is a web-based agriculture platform designed to help farmers and agricultural enthusiasts access farming information and purchase agricultural products online.

The platform provides a single place where users can:

- Browse agriculture-related products
- Purchase seeds, fertilizers, and machinery
- Read agricultural blogs
- Access farming information
- Explore agricultural schemes and programmes
- Search products by category

This project was developed as a **Minor Project for the Bachelor of Computer Applications (BCA)** curriculum.

---

## 🎯 Problem Statement

Farmers often face challenges while purchasing agricultural products because:

- Similar products are available at different prices.
- Trusted agricultural information is scattered across different sources.
- Comparing products is difficult.
- Access to modern agricultural resources is limited.

AgroPride was designed to simplify product discovery and make agricultural resources available through a single digital platform.
